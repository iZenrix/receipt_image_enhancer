# Changelog

All notable changes to this package are documented in this file.

## 0.1.0

- Initial release: on-device receipt enhancement via Dart FFI and OpenCV 4.12.0.
- Presets: `balanced`, `readable`, `scan`.
- APIs: `enhanceFile`, `enhanceBytes`, `detectDocumentFile`.
- Optional document detection with perspective correction and full-frame fallback.
- Android (API 24+) and iOS 15+.
